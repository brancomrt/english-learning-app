English Learning App

Política de Privacidade — Última atualização: setembro de 2026

Resumo: Este aplicativo não coleta, armazena nem transmite dados pessoais. Todo o seu progresso fica exclusivamente no seu dispositivo.

1. Visão Geral

O English Learning App é um aplicativo de aprendizado de inglês que funciona inteiramente no seu dispositivo. Esta política explica de forma transparente quais dados são utilizados e como são tratados, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

2. Dados que NÃO coletamos

Este aplicativo não coleta, armazena, transmite ou compartilha:

  • Nome, e-mail, CPF ou qualquer dado pessoal identificável
  • Localização geográfica
  • Contatos do dispositivo
  • Histórico de navegação
  • Dados biométricos ou de reconhecimento facial
  • Informações de pagamento
  • Dados de uso para fins analíticos ou publicitários
  • Identificadores de publicidade (GAID/IDFA)

3. Dados armazenados localmente

O aplicativo armazena apenas no seu dispositivo, exclusivamente para o funcionamento do app:

  • Progresso nos exercícios (pontuação, XP acumulado, streak diário)
  • Conquistas desbloqueadas
  • Preferências de configuração (número de questões por nível)
  • Indicador de conclusão do tutorial inicial

Esses dados são completamente anônimos, não o identificam e nunca saem do dispositivo. São automaticamente apagados ao desinstalar o aplicativo.

4. Acesso à internet

O aplicativo utiliza internet somente para carregar imagens ilustrativas do vocabulário, servidas pelo serviço Pexels. Nenhuma informação pessoal é enviada nessas requisições — apenas o endereço IP do dispositivo é registrado nos logs do CDN, o que é padrão de qualquer acesso à internet. Consulte a política de privacidade do Pexels.

5. Reconhecimento de voz

O recurso de resposta por voz utiliza o serviço de reconhecimento de fala nativo do Android (Google Speech Services), já instalado no dispositivo. O aplicativo não grava, armazena nem processa o áudio — ele é enviado diretamente pelo sistema Android ao Google e convertido em texto. Consulte a política de privacidade do Google.

6. Permissões solicitadas

  • INTERNET — necessária para carregar imagens do vocabulário
  • RECORD_AUDIO — necessária para o recurso de resposta por voz

Nenhuma outra permissão é solicitada.

7. Crianças

Este aplicativo não é direcionado a crianças menores de 13 anos e não coleta conscientemente dados de crianças. Por não haver coleta de dados pessoais, o aplicativo não apresenta riscos específicos para este público.

8. Seus direitos (LGPD)

Nos termos da LGPD, você tem direito ao acesso, correção, exclusão e portabilidade dos seus dados. Como todos os dados são armazenados localmente no seu dispositivo, você pode exercer esses direitos a qualquer momento:

  • Para apagar todos os dados: desinstale o aplicativo
  • Para apagar dados de progresso: Configurações do Android → Aplicativos → English Learning App → Limpar dados

9. Alterações nesta política

Eventuais atualizações serão refletidas na data de "Última atualização" no topo deste documento e na tela de Política de Privacidade dentro do aplicativo.
